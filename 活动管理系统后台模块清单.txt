# 活动管理系统后台 - 本科毕业设计精简版模块清单
## (当前版本：已补全功能与技术亮点)

## 一、核心业务模块（已构建系统闭环）

### 1. 活动管理模块
- 活动创建、编辑、删除（CRUD）
- 活动状态管理（草稿/待发布/已发布/进行中/已结束/已取消）
- 活动分页查询（支持分类筛选和关键字 ES 模糊搜索）
- 活动详情查看与分类管理

### 2. 报名管理模块
- 用户报名活动（基于 RabbitMQ 异步削峰处理） ⭐
- 管理员审核报名（单审通过/驳回）
- 报名列表查询与状态展示
- 报名数据导出（Excel）

### 3. 签到管理模块
- 生成活动签到码（6位限时签到码）
- 用户输入签到码签到
- 管理员手动代签（支持自动拉取未签到名单） ⭐
- 签到列表查询与数据导出（Excel）

### 4. 用户与权限控制模块（RBAC 深度细分）
- 用户注册与登录（JWT 认证）
- **角色细分**：超级管理员（管理用户与分配角色） vs 管理员（管理活动与业务） ⭐
- 志愿者个人中心：时长统计、积分展示、活动记录
- **亮点**：志愿者电子证书导出（PDF 自动生成） ⭐

## 二、亮点与扩展模块（毕设加分项）

### 5. 活动评价与互动模块 ⭐
- 用户提交评价（1-5星评分 + 文字内容）
- 评价列表展示与分页
- 评价点赞功能
- **亮点**：敏感词过滤机制（基于本地字典库）

### 6. 活动推荐模块 ⭐
- **基础推荐**：基于热门度（报名数/浏览量）的热门活动推荐
- **搜索推荐**：基于 Elasticsearch 的全文检索与相关度排序

### 7. 数据统计与可视化模块 ⭐
- 总体统计数据展示（总用户数、总活动数、总报名数、总签到数）
- 基于 ECharts 的可视化大屏（近7天报名人数趋势折线图、活动分类占比饼图）
- **实时性**：利用 WebSocket 实现签到数据实时动态更新

## 三、技术栈架构

- **后端框架**：Spring Boot 3.1.5
- **数据库**：MySQL 8.0 + MyBatis Plus 3.5.3
- **搜索引擎**：Elasticsearch 8.x (用于活动搜索与推荐)
- **消息队列**：RabbitMQ (用于报名请求削峰与系统通知)
- **缓存/实时性**：Redis (签到码/Token) + WebSocket (实时推送)
- **文件处理**：Apache POI (Excel) + iText (PDF 证书生成)
- **前端**：Vue 3 + TypeScript + Element Plus + Tailwind CSS + ECharts
