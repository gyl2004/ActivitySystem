摘    要
随着我国公益事业数字化转型不断推进，传统公益活动管理方式存在信息传播效率低、人工统计易出错、志愿者匹配度不高、签到管理不规范等问题，已难以满足公益组织日常运营需求。为解决上述痛点，本文设计并实现一套基于 SpringBoot 的公益活动管理系统。
系统采用前后端分离架构，后端以 Spring Boot 3.1.5 为核心框架，基于 Java 17 开发；前端使用 Vue 3 构建响应式界面；数据存储采用 MySQL，配合 Redis、RabbitMQ、Elasticsearch 提升系统性能与扩展性。系统实现用户管理、活动管理、报名管理、签到管理、消息通知、智能推荐、评价反馈等核心功能，支持普通用户、活动组织者、系统管理员三级权限控制。通过融合协同过滤与内容推荐的混合算法，实现公益活动个性化推荐，可有效提升志愿者参与体验与活动匹配效率。
经测试，系统功能完整、运行稳定，能够支持千级并发访问，满足中小型公益组织的实际使用需求，对推动公益事业数字化、规范化发展具有实际应用价值。
关键词：SpringBoot；公益活动管理；前后端分离；智能推荐；Redis









ABSTRACT
With the continuous advancement of digital transformation in China's public welfare undertakings, traditional public welfare activity management methods have problems such as low information dissemination efficiency, error-prone manual statistics, low volunteer matching degree, and non-standard check-in management, which are difficult to meet the daily operation needs of public welfare organizations. To solve the above pain points, this paper designs and implements a public welfare activity management system based on SpringBoot.
The system adopts a front-end and back-end separation architecture. The back-end takes Spring Boot 3.1.5 as the core framework and is developed based on Java 17. The front-end uses Vue 3 to build a responsive interface. MySQL is used for data storage, and Redis, RabbitMQ, and Elasticsearch are combined to improve system performance and scalability. The system implements core functions such as user management, activity management, registration management, check-in management, message notification, intelligent recommendation, and evaluation feedback, supporting three-level permission control for ordinary users, activity organizers, and system administrators. Through a hybrid algorithm integrating collaborative filtering and content recommendation, personalized recommendation of public welfare activities is realized, which can effectively improve volunteer participation experience and activity matching efficiency.
Tests show that the system has complete functions and stable operation, can support thousands of concurrent accesses, meets the actual use needs of small and medium-sized public welfare organizations, and has practical application value for promoting the digital and standardized development of public welfare undertakings.

Key words: SpringBoot; Public Welfare Management; Separation of Front and Back Ends; Intelligent Recommendation; Redis
